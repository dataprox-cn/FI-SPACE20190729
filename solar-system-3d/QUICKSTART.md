# Quick Start Guide

Get the 3D Solar System Explorer running in 5 minutes!

## 🚀 Installation

### Prerequisites
- Node.js 16 or higher ([Download](https://nodejs.org/))
- A modern web browser (Chrome, Edge, or Firefox)

### Steps

1. **Navigate to the project folder**
   ```bash
   cd solar-system-3d
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```
   ⏱️ This takes about 1-2 minutes

3. **Start the development server**
   ```bash
   npm run dev
   ```
   
4. **Open in browser**
   - The app should automatically open at `http://localhost:5173`
   - If not, manually open that URL in your browser

5. **Enjoy!** 🎉

## 🎮 First Steps

### Navigation Basics
- **Rotate** - Click and drag with left mouse button
- **Zoom** - Scroll wheel (or pinch on touchpad)
- **Pan** - Right-click and drag (or Ctrl+left-click drag)

### Try These First

1. **Search for Earth**
   - Type `earth` in the search box (top center)
   - Click the planet when it's highlighted
   - View details and click "View on NASA Science"

2. **Find a Famous Asteroid**
   - Search for `1` (Ceres - largest asteroid)
   - Or `99942` (Apophis - close approach in 2029)
   - Or `433` (Eros - spacecraft landing site)

3. **Filter by Class**
   - Look at bottom-right "Legend & Filters"
   - Click "Mars-Crosser" to hide the red asteroids
   - Click again to show them

4. **Speed Up Time**
   - Bottom-left time controls
   - Try 10x or 100x speed
   - Watch the inner planets zoom around!

## 🌟 Cool Things to Explore

### Planets
Search for these (just type the name):
- `mercury` `venus` `earth` `mars`
- `jupiter` `saturn` `uranus` `neptune`

### Famous Asteroids
- `1` - Ceres (dwarf planet, 939 km!)
- `4` - Vesta (brightest asteroid visible from Earth)
- `99942` - Apophis (will pass very close to Earth in 2029)
- `101955` - Bennu (OSIRIS-REx brought samples back!)
- `65803` - Didymos (NASA crashed a spacecraft into it!)

### Largest Objects
- `134340` - Pluto (yes, it's here!)
- `2` - Pallas (545 km)
- `10` - Hygiea (407 km)

## 🎨 Understanding the Colors

Look for these in the visualization:

- **Cyan dots** 🩵 - Main Belt (most common, between Mars & Jupiter)
- **Red dots** 🔴 - Mars-Crossers (cross Mars' orbit)
- **Pink dots** 🌸 - Jupiter Trojans (leading/trailing Jupiter)
- **Yellow-green dots** 🟢 - Near-Earth Objects (potentially hazardous!)
- **Teal dots** 💚 - Trans-Neptunian (beyond Neptune, like Pluto)

## ⚙️ Performance Tips

### If it's running slowly:
1. Click **"Quality: HIGH"** button (bottom-left)
2. Change to **"Quality: LOW"**
3. Close other browser tabs
4. Use Chrome or Edge (better WebGL performance)

### If asteroids are missing:
- Check the **Legend & Filters** panel (bottom-right)
- You may have accidentally hidden a class
- Click to toggle visibility back on

## 🐛 Troubleshooting

### Blank screen?
- Wait 5-10 seconds for data to load (18,000 objects)
- Check browser console (press F12) for errors
- Try hard refresh: `Ctrl+Shift+R` (Win) or `Cmd+Shift+R` (Mac)

### Search not working?
- Planet names: type the full name like `earth` or `mars`
- Asteroids: use the number ID like `1` or `433`
- Case doesn't matter: `EARTH` and `earth` both work

### Can't see planets?
- Zoom out! They might be behind you
- Click the Sun in the center and zoom out from there
- Or just search for the planet name
